# Roadmap (themes)

Kletron moves fast; this file tracks **direction**, not dates. For execution detail, use GitHub Issues / Projects on your fork.

## 1. Plugins & ecosystem

- More **workspace MCP** examples (stdio, SSE, HTTP) under `community/mcp-servers/`.
- **Graph preset** library and import/export polish.
- Skills marketplace hygiene (document formats, validation messages).

## 2. Local-first / BYOK

- Smoother **Ollama / LM Studio / vLLM** presets and docs.
- Clearer “no cloud keys required” dev path in `env.example` + README.

## 3. Graph editor & observability

- Graph UX for branching, approvals, and trace readability.
- Better run replay affordances for audits.

## 4. Docs & contributor experience

- Keep the **15-minute quickstart** true on Linux + Windows.
- Expand architecture notes where contributors get lost (link from `ARCHITECTURE.md`).

## How to propose work

Open an issue with label **`design discussion`** for anything that changes persistence shape, auth, or graph JSON contracts. Smaller improvements can go straight to PR with **`help wanted`** self-serve.
