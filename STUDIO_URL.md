## 🚀 Quick Start

1. **Open Chrome or Firefox**
2. **Paste the Studio URL above**
3. **Wait for Studio to load** (may take 30 seconds)
4. **Select `finance_analyzer` graph**
5. **Paste CSV data** into `raw_csv` field
6. **Click Submit** to run!

## 💡 Sample CSV

```csv
Segment,Country,Product,Sales,Profit

Government,Germany,Carretera,26420,13210

```

## ⚠️ If It Doesn't Work

1. Make sure server is running (check terminal)
2. Try hard refresh: `Cmd+Shift+R` (Mac) or `Ctrl+Shift+R` (Windows)
3. Check browser console (F12) for errors
4. Make sure you're using Chrome/Firefox, not Safari
