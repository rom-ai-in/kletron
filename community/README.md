# Community contributions

This folder is for **plugin-shaped work** that scales contributor buzz without everyone editing core runtime code first.

## Wedge (what we’re optimizing for)

- **Headline:** MCP-native agent graphs with a real UI.
- **Pillar:** Local-first / BYOK — bring keys or run models on your laptop.

PRs here should be **small, testable, and documented**.

## What belongs here

| Path | Examples |
|------|-----------|
| `community/mcp-servers/` | Templates + tiny reference MCP servers |
| `community/graph-presets/` | JSON graph exports (document schema + how to load) |
| `community/skills/` | Example `SKILL.md` files matching Kletron’s skill front matter |

## Quality bar

- README in every new folder: purpose, how to run, limitations.
- No secrets in commits; use `env.example` patterns.
- Prefer examples that run against [`examples/quickstart-workspace`](../examples/quickstart-workspace/).

## Recognition

Contributors are listed in [CONTRIBUTORS.md](../CONTRIBUTORS.md) and release notes. Add your GitHub handle in the PR description if you want a specific spelling.
